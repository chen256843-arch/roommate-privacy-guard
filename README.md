# 隐私卫士 / Privacy Guard 2.4

Windows 本地摄像头防窥与无感取证工具。全部在本机离线运行，不上传任何画面。

主要功能：

- **全屏黑屏提示**：检测到**两张或更多可见人脸**并持续设定时长后，所有屏幕立即变为纯黑，只显示四个大字「注意隐私」，不显示人数或任何画面内容。
- **布防 / 撤防**：黑屏时按 `Esc` 为**撤防**，之后需手动「重新布防」才会再次生效；按**其他任意键**为**暂离**，经设定时间（默认 60 秒，可在界面调节 5–1800 秒）后自动重新布防。
- **无感录像（两人）**：检测到两人时自动录制摄像头，可选同时录屏。录像不在桌面显示任何提示，文件带时间戳，仅保存在本机。
- **卫兵模式（本人识别）**：先「录入本人面孔」建立本地模板，开启后，当画面中只有**一个非本人**独自在屏幕前时，自动录制**摄像头与屏幕**，用于离开电脑时取证。
- **录音**：可选择录像时同时录制麦克风（`audio.wav`，与视频放在同一会话文件夹）。
- **两人抓拍**：检测到两人时自动抓拍摄像头照片（不带检测框），可选同时截屏；截屏在黑屏出现之前完成。每次两人事件抓拍一次，撤防或暂离时照常抓拍。
- **人走后本人在场自动关黑屏**：已录入本人面孔时，其他人离开、画面中只剩被识别为本人的一人并持续约 1.5 秒，黑屏自动关闭并保持布防；只剩陌生人或无人时黑屏不关。可在「录像与设置」关闭，关闭后仍用按键退出。
- **无人值守先抓拍再录像**：卫兵模式触发（只有一个非本人独自在前）时，先拍摄像头照片并截屏，再开始录像；每次触发只拍一次。可在「录像与设置」关闭。
- **二级密码保护**：可设置二级密码。设置后，更改/查看保存路径、打开文件夹、重新录入本人、关闭卫兵模式都需要密码；保存路径**正常状态下隐藏**，点「显示路径」并通过密码验证后才显示。
- **一键清理（密码＋人脸）**：一键永久删除全部录像与截图，需要二级密码**并**通过本人人脸验证（须先开始监测、已录入本人）。用于确认本人在场时快速清场。注意：这是应用内保护，不能阻止直接访问磁盘文件的人；清理不可恢复。
- **可调的录像停止**：两人录像的停止延迟、卫兵录像的停止延迟、单段最长录像（超时自动分段，0 为不限）、手动录像自动停止时间，均可在「录像与设置」页调节。检测置信度、提示时长、自动布防时间等可调参数也集中在该页。
- **分开存放、可选路径**：录像（摄像头 / 屏幕 / 录音）与抓拍（照片 / 截图）存放在两个不同的文件夹，均可在「录像与设置」页更改；两者不能选同一个文件夹。
- **全部可手动启动**：黑屏提示、摄像头＋屏幕录像、抓拍、重新布防均可手动触发。

检测使用 OpenCV Zoo 的 **YuNet**（人脸检测）与 **SFace**（人脸识别），模型随包提供，可离线使用。

## 直接使用

提供三种形式，功能完全相同，均无需安装 Python、VC++ 运行库或其他环境（已全部打包），也不需要管理员权限：

- **便携版 `PrivacyGuard-Portable.zip`（推荐）**：解压后得到 `PrivacyGuard.exe`、`portable.ini`、`data` 文件夹和说明文件。因为有 `portable.ini`，设置、本人特征、录像（`data\recordings`）与抓拍（`data\snapshots`）都保存在程序旁的 `data` 中，整个文件夹可移动或放在 U 盘使用；删除 `portable.ini` 则改存用户目录。文件夹不可写时自动改存用户目录。
- **单文件版 `PrivacyGuard.exe`**：只有一个文件，可直接复制到任何位置双击运行。每次启动会先解压到临时文件夹，因此启动比文件夹版慢几秒；个别杀毒软件对单文件程序更敏感，如被拦截可改用文件夹版。
- **文件夹版 `PrivacyGuard-Windows.zip`**：解压全部内容后运行其中的 `PrivacyGuard.exe`（需与 `_internal` 一起保留），启动更快。

1. 选择以上任一形式，双击 `PrivacyGuard.exe`。
2. 单文件版与文件夹版的录像、抓拍和设置保存在用户目录 `PrivacyGuard` 下；便携版保存在程序旁的 `data` 文件夹。
3. 选择摄像头并点击「开始监测」。首次使用时，在 Windows 设置 → 隐私和安全性 → 摄像头中，允许桌面应用访问摄像头。
4. 点击「测试黑屏提示」可先查看黑屏效果（不打开摄像头，也不计入提醒次数）。
5. 需要卫兵模式时：开始监测后点击「录入本人面孔」，正对摄像头缓慢转动头部完成采集，再勾选「卫兵模式」。

点击「收起到托盘」可继续后台运行；右键托盘图标可恢复窗口、停止或退出。切换摄像头、置信度或持续时间前，请先停止监测。

支持 Windows 10/11 x64。该版本在当前 Windows 环境完成打包与无摄像头运行验证，尚未做真实摄像头现场验证或其他 Windows 设备兼容性测试。

## 录像与隐私

- 录像、录音、抓拍均为**无感模式**：期间不在桌面显示任何窗口、图标或提示。
- 默认保存位置：录像 `C:\Users\<你的用户名>\PrivacyGuard\recordings`，抓拍 `C:\Users\<你的用户名>\PrivacyGuard\snapshots`。可在「录像与设置」页「更改…」为任意可写文件夹（支持中文路径），「打开」直接打开。更改后新的录像与抓拍写入新位置。
- 每次录像单独一个带时间戳的文件夹，内含 `camera.mp4`（摄像头）、`screen.mp4`（屏幕，按需）、`audio.wav`（录音，按需）。视频每一帧都烧录了 `YYYY-MM-DD HH:MM:SS` 时间戳；录音无法烧录时间戳，以所在文件夹的时间戳为准，约在录像开始 0.5 秒后接入（Windows 打开麦克风所需时间）。
- 抓拍文件名形如 `2026-10-24_15-30-00_多人_camera.jpg` / `..._screen.jpg`，图片上同样带时间戳。
- 录音使用 Windows 默认麦克风（winmm，经 `ctypes` 调用）。麦克风不可用时状态栏显示「录音不可用」，视频录制不受影响。录音会录下他人声音，请遵守当地关于录音的法律规定。
- 录像、识别、设置**全部只保存在本机，不上传**。本人面孔只保存为本地特征向量（`PrivacyGuard\owner.npy`），不保存原始图像。
- 正常监测（未触发录像）时不写入任何画面；预览窗口本身不保存。
- 屏幕录制与截屏使用 Windows 系统接口（GDI，经 `ctypes` 调用），不依赖额外的第三方库。

## 检测与边界

- 模型在本机 CPU 上离线运行。两人提示依据可见人脸数量，不判断谁在注视屏幕。
- 卫兵模式依据本人特征匹配（余弦相似度阈值 0.363）。侧脸、口罩、遮挡、暗光、妆容或光线变化可能导致漏检或误判（把本人当陌生人或相反）。
- 照片、屏幕中的人脸可能被计入或被识别。
- 默认置信度 0.80，检测上限约 10 帧/秒。
- 摄像头打不开、被占用或持续读取失败时，软件会停止监测并显示原因。
- 黑屏提示不会锁定电脑，也不会覆盖系统锁屏或 Windows 安全桌面。它属于隐私辅助，不能保证阻止窥视或替代系统级安全措施。

## GitHub 识别项目

使用 OpenCV 官方 [opencv/opencv_zoo](https://github.com/opencv/opencv_zoo)，通过 `cv2.FaceDetectorYN` 与 `cv2.FaceRecognizerSF` 调用模型，没有复制整个仓库。

| 模型 | 文件 | 字节 | SHA-256 | 许可证 |
| --- | --- | --- | --- | --- |
| YuNet 人脸检测 | `face_detection_yunet_2023mar.onnx` | 232589 | `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4` | MIT（`assets/YuNet-LICENSE.txt`） |
| SFace 人脸识别 | `face_recognition_sface_2021dec.onnx` | 38696353 | `0ba9fbfa01b5270c96627c4ef784da859931e02f04419c829e83484087c34e79` | Apache-2.0（`assets/SFace-LICENSE.txt`） |

软件启动监测前会核对 YuNet 模型 SHA-256，缺失或损坏时提示重新解压。固定 OpenCV 4.11 与上述模型版本以保持兼容。

## 从源码运行

使用 Python 3.12 x64。在本目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

模型已包含在 `assets` 内，无需额外下载。未新增运行依赖（屏幕录制使用系统 GDI，录音使用系统 winmm）。

$env:QT_QPA_PLATFORM = 'offscreen'

可使用 `--screenshot C:\path\main.png [--page 1]` 或 `--alert-screenshot C:\path\alert.png` 渲染演示界面并退出（`--page`：0 实时监测，1 录像与设置，2 使用说明）。

## 重新打包

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\build.ps1 -Python .\.venv\Scripts\python.exe
```

输出位于本目录 `dist/PrivacyGuard`。生成单文件版时加 `-OneFile`（`.\build.ps1 -Python .\.venv\Scripts\python.exe -OneFile`），输出为 `dist/PrivacyGuard.exe`。文件夹版需分发整个目录，不能只复制 EXE；`_internal` 内包含动态链接的 Qt 库和模型。许可证及依赖来源见 `THIRD_PARTY_NOTICES.md` 与 `assets/licenses`。
